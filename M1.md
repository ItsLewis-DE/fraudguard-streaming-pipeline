## 1. Các quyết định kiến trúc đã chốt

### 1.1 Một ClickHouse database

Trong ClickHouse, khái niệm tương đương schema của nhiều hệ quản trị chính là
database. Vì dự án local này không cần tách quyền theo từng lớp dữ liệu, tất cả
model dbt sẽ materialize trong database `fraudguard`.

Các tên `staging`, `intermediate`, `core`, `ml`, `analytics` và `monitoring` chỉ
là:

- thư mục tổ chức model;
- tag dbt;
- lớp logic trong lineage;
- không phải database ClickHouse riêng.

Việc này đơn giản hóa local setup và tránh tạo các database có tên ghép từ
target schema. Trade-off là namespace vật lý phẳng; tên model phải đủ rõ và
không được trùng nhau.

### 1.2 Không tạo thêm role hoặc user cho M1

M1 dùng user hiện có `fraudguard_transformer` và role hiện có
`fraudguard_transformer_role`. Không tạo ML reader, không thêm password hay
service mới vào Compose.

Vì role transformer có quyền ghi để dbt materialize model, CLI kiểm tra contract
phải mở session với `readonly=1`. Đây là hàng rào an toàn cho tiến trình CLI,
không phải least-privilege tuyệt đối ở cấp credential. Nếu sau này có model
serving hoặc nhiều người dùng chung môi trường, tách read-only user là hardening
làm sau.

### 1.3 Training relation giữ hẹp

Training relation có đúng 16 cột, theo đúng thứ tự:

1. `source`
2. `event_id`
3. `event_time`
4. `event_date`
5. `step`
6. `transaction_type`
7. `amount`
8. `origin_balance_before`
9. `origin_balance_after`
10. `destination_balance_before`
11. `destination_balance_after`
12. `origin_balance_delta`
13. `destination_balance_delta`
14. `origin_amount_residual`
15. `destination_amount_residual`
16. `is_fraud`

Không đưa account ID, raw Kafka metadata, MinIO path, eligibility flags hay
exclusion reason vào relation dùng cho training. Lineage được bảo toàn theo key
`(source, event_id)` về `fct_transactions`, qua committed ingestion batch và
qua `manifest.json` của dbt.

### 1.4 Phân nhóm cột

- Identity/lineage: `source`, `event_id`.
- Time/split: `event_time`, `event_date`, `step`.
- Target: `is_fraud`.
- Feature đầu vào an toàn ở prediction point:
  `transaction_type`, `amount`, `origin_balance_before`,
  `destination_balance_before`.
- Audit candidate, chưa mặc định cho model:
  hai after-balance, hai balance delta và hai amount residual.

After-balance tồn tại ở `post_ledger_update`, nhưng có thể tạo shortcut mạnh
trên PaySim. M1 chỉ kiểm chứng công thức và schema; milestone training phải chạy
ablation trước khi cho các cột audit candidate vào feature set.

## A1. Regression test cho Spark quality schema

Mục đích là khóa exact output schema của `build_quality_manifest`. Test không
chạy Kafka, MinIO hay streaming query; nó chỉ tạo DataFrame nhỏ và gọi pure
batch transformation.

**File đích:** `spark/tests/test_kafka_minio_landing.py`
```python
from __future__ import annotations

from pyspark.sql import SparkSession
from pyspark.sql.functions import col
from pyspark.sql.types import StringType, StructField, StructType

from spark.jobs.kafka_minio_landing import (
    LandingConfig,
    build_quality_manifest,
)


def test_quality_manifest_has_exact_schema(
    spark: SparkSession,
    transaction_landing_config: LandingConfig,
) -> None:
    batch_schema = StructType([StructField("quarantine_reason", StringType(), True)])
    batch_df = spark.createDataFrame(
        [("INVALID_CONFLUENT_MAGIC_BYTE",)],
        batch_schema,
    )

    record_schema = StructType(
        [
            StructField("source", StringType(), True),
            StructField("event_time", StringType(), True),
        ]
    )
    decoded_schema = StructType(
        [
            StructField("record", record_schema, True),
            StructField("quarantine_reason", StringType(), True),
        ]
    )
    decoded_df = spark.createDataFrame(
        [(("paysim", "2026-01-01T00:00:00Z"), None)],
        decoded_schema,
    ).withColumn(
        "record",
        col("record").withField(
            "event_time",
            col("record.event_time").cast("timestamp"),
        ),
    )

    actual = build_quality_manifest(
        batch_df=batch_df,
        decoded_df=decoded_df,
        config=transaction_landing_config,
        batch_id=7,
    )

    assert tuple(
        (field.name, field.dataType.simpleString()) for field in actual.schema.fields
    ) == (
        ("pipeline", "string"),
        ("batch_id", "bigint"),
        ("event_date", "date"),
        ("source", "string"),
        ("input_rows", "bigint"),
        ("valid_rows", "bigint"),
        ("quarantine_rows", "bigint"),
    )
    assert {
        (row["input_rows"], row["valid_rows"], row["quarantine_rows"])
        for row in actual.collect()
    } == {(1, 0, 1), (1, 1, 0)}
```

Nếu Spark suy ra nullability khác do version, không nới test một cách mù quáng.
Trước hết kiểm tra contract consumer trong Airflow và ClickHouse. Exact name,
order và type là bắt buộc; nullability phải phản ánh output thực tế ổn định.

## A4. Sửa `has_final_label` bằng match marker

ClickHouse có thể điền default value ở phía không match của `LEFT JOIN` khi
`join_use_nulls=0`. Vì vậy `l.event_id IS NOT NULL` không phải bằng chứng match
đáng tin cậy. Tạo marker hằng số ở CTE phía label rồi kiểm tra marker.

**File đích:** `dbt/models/marts/core/fct_transactions_labeled.sql`
```sql
with final_labels as (
    select
        *,
        toUInt8(1) as label_matched
    from {{ ref('fct_transaction_labels') }}
)
select
    t.*,
    l.is_fraud,
    l.is_flagged_fraud,
    l.label_matched = 1 as has_final_label,
    ifNull(l.has_payload_conflict, false) as has_label_payload_conflict
from {{ ref('fct_transactions') }} as t
left join final_labels as l
    on t.source = l.source
   and t.event_id = l.event_id
```

Không dùng `event_id = ''`, `batch_id = 0` hoặc một business value bất kỳ làm
sentinel cho “không match”. Các giá trị đó có thể là dữ liệu thật hoặc default
value của ClickHouse.

## A6. Key reconciliation không dùng sentinel

Thay các test `LEFT JOIN ... WHERE event_id = ''` bằng marker rõ ràng. Pattern
này áp dụng cho candidate/canonical, eligible/training và orphan label.

**File đích:** `dbt/tests/assert_ml_candidates_match_canonical_transactions.sql`
```sql
with candidate_keys as (
    select source, event_id, toUInt8(1) as candidate_matched
    from {{ ref('ml_training_candidates') }}
),
canonical_keys as (
    select source, event_id, toUInt8(1) as canonical_matched
    from {{ ref('fct_transactions') }}
),
missing_candidate as (
    select
        c.source,
        c.event_id,
        'missing_candidate' as contract_error
    from canonical_keys as c
    left join candidate_keys as m using (source, event_id)
    where ifNull(m.candidate_matched, 0) = 0
),
unexpected_candidate as (
    select
        m.source,
        m.event_id,
        'unexpected_candidate' as contract_error
    from candidate_keys as m
    left join canonical_keys as c using (source, event_id)
    where ifNull(c.canonical_matched, 0) = 0
)
select * from missing_candidate
union all
select * from unexpected_candidate
```

**File đích:** `dbt/tests/assert_training_relation_matches_eligible_candidates.sql`

## A7. Lineage chỉ đi qua committed batch

Training row không mang Kafka/MinIO metadata trực tiếp, nhưng canonical
transaction tạo ra nó phải truy được về physical row thuộc batch đã commit.
Test dùng marker, không dùng batch ID sentinel.

**File đích:** `dbt/tests/assert_canonical_transactions_have_committed_lineage.sql`
```sql
with committed as (
    select
        pipeline,
        batch_id,
        toUInt8(1) as batch_matched
    from {{ ref('int_committed_ingestion_batches') }}
),
transaction_lineage as (
    select
        source,
        event_id,
        pipeline,
        batch_id
    from {{ ref('int_transactions_ranked') }}
    where canonical_rank = 1
)
select
    t.source,
    t.event_id,
    t.pipeline,
    t.batch_id
from transaction_lineage as t
left join committed as c
    on t.pipeline = c.pipeline
   and t.batch_id = c.batch_id
where ifNull(c.batch_matched, 0) = 0
```

Tên `canonical_rank`, `pipeline` và `batch_id` phải được đối chiếu với SQL hiện
tại trước khi triển khai. Nếu model hiện dùng alias khác, giữ semantic hiện tại
và cập nhật test theo tên thật; không thêm cột chỉ để khớp tài liệu.

## B3. Typed contract, safe identifiers và validator

Module này là nguồn chân lý cho parse config và validation. Identifier không
được truyền qua query parameter, nên phải validate bằng regex rồi quote.
Business value luôn truyền bằng parameter. Code dưới đây chốt interface và
thuật toán; implementation có thể tách pure helper miễn không đổi contract.

**File đích:** `ml/src/fraudguard_ml/training_data_contract.py`
```python
from __future__ import annotations

import re
from collections.abc import Mapping, Sequence
from dataclasses import dataclass
from datetime import UTC, datetime
from typing import Any, Literal, Protocol, Self

from pydantic import BaseModel, ConfigDict, field_validator, model_validator

IDENTIFIER = re.compile(r"^[A-Za-z_][A-Za-z0-9_]*$")
RELATION = re.compile(
    r"^(?P<database>[A-Za-z_][A-Za-z0-9_]*)"
    r"\.(?P<table>[A-Za-z_][A-Za-z0-9_]*)$"
)


class DataContractError(RuntimeError):
    """A safe, user-facing contract failure without credentials or SQL."""


class QueryResult(Protocol):
    column_names: Sequence[str]
    result_rows: Sequence[Sequence[Any]]


class ClickHouseClient(Protocol):
    def query(
        self,
        query: str,
        parameters: Mapping[str, Any] | None = None,
    ) -> QueryResult: ...


class FrozenStrictModel(BaseModel):
    model_config = ConfigDict(strict=True, frozen=True, extra="forbid")


class ExpectedColumn(FrozenStrictModel):
    name: str
    clickhouse_type: str


@dataclass(frozen=True)
class RelationName:
    database: str
    table: str

    @classmethod
    def parse(cls, value: str) -> RelationName:
        match = RELATION.fullmatch(value)
        if match is None:
            raise DataContractError("relation must be database.table")
        return cls(**match.groupdict())

    def quoted(self) -> str:
        return f"`{self.database}`.`{self.table}`"


class TrainingDataContractConfig(FrozenStrictModel):
    schema_version: Literal[1]
    dataset_name: Literal["paysim_training_transactions_v1"]
    relation: str
    lineage_relation: str
    source_column: Literal["source"]
    expected_source: Literal["paysim"]
    prediction_point: Literal["post_ledger_update"]
    primary_key: tuple[str, ...]
    event_time_column: Literal["event_time"]
    step_column: Literal["step"]
    target_column: Literal["is_fraud"]
    transaction_type_column: Literal["transaction_type"]
    replay_epoch_utc: datetime
    transaction_type_domain: tuple[str, ...]
    expected_columns: tuple[ExpectedColumn, ...]
    prohibited_relation_columns: tuple[str, ...]
    non_feature_columns: tuple[str, ...]
    audit_candidate_columns: tuple[str, ...]

    @field_validator(
        "primary_key",
        "transaction_type_domain",
        "expected_columns",
        "prohibited_relation_columns",
        "non_feature_columns",
        "audit_candidate_columns",
        mode="before",
    )
    @classmethod
    def freeze_sequences(cls, value: object) -> object:
        return tuple(value) if isinstance(value, list) else value

    @field_validator("replay_epoch_utc")
    @classmethod
    def require_utc(cls, value: datetime) -> datetime:
        if value.tzinfo is None or value.utcoffset() != UTC.utcoffset(value):
            raise ValueError("replay_epoch_utc must be timezone-aware UTC")
        return value.astimezone(UTC)

    @model_validator(mode="after")
    def validate_sets(self) -> Self:
        names = tuple(column.name for column in self.expected_columns)
        expected = set(names)
        groups: dict[str, tuple[str, ...]] = {
            "expected_columns": names,
            "primary_key": self.primary_key,
            "transaction_type_domain": self.transaction_type_domain,
            "prohibited_relation_columns": self.prohibited_relation_columns,
            "non_feature_columns": self.non_feature_columns,
            "audit_candidate_columns": self.audit_candidate_columns,
        }
        for label, values in groups.items():
            if not values:
                raise ValueError(f"{label} must not be empty")
            if len(values) != len(set(values)):
                raise ValueError(f"{label} contains duplicates")

        RelationName.parse(self.relation)
        RelationName.parse(self.lineage_relation)
        for column in (
            *names,
            *self.primary_key,
            *self.non_feature_columns,
            *self.audit_candidate_columns,
        ):
            if IDENTIFIER.fullmatch(column) is None:
                raise ValueError(f"invalid ClickHouse identifier: {column}")

        if not set(self.primary_key) <= expected:
            raise ValueError("primary_key must be in expected_columns")
        if not set(self.primary_key) <= set(self.non_feature_columns):
            raise ValueError("primary_key must be non-feature")
        if not set(self.non_feature_columns) <= expected:
            raise ValueError("non_feature_columns must be expected")
        if not set(self.audit_candidate_columns) <= expected:
            raise ValueError("audit candidates must be expected")
        if expected & set(self.prohibited_relation_columns):
            raise ValueError("expected and prohibited columns overlap")
        if set(self.non_feature_columns) & set(self.audit_candidate_columns):
            raise ValueError("non-feature and audit columns overlap")
        return self


@dataclass(frozen=True)
class ContractMetrics:
    row_count: int
    distinct_key_count: int
    empty_key_count: int
    null_count: int
    invalid_source_count: int
    invalid_type_count: int
    invalid_target_count: int
    invalid_time_count: int
    invalid_formula_count: int
    missing_lineage_count: int


@dataclass(frozen=True)
class ValidationReport:
    dataset_name: str
    relation: str
    validated_at_utc: str
    schema: tuple[tuple[str, str], ...]
    metrics: ContractMetrics


def parse_one_metrics_row(
    result: QueryResult,
    expected_columns: tuple[str, ...],
) -> tuple[int, ...]:
    if tuple(result.column_names) != expected_columns:
        raise DataContractError("metrics query returned unexpected columns")
    if len(result.result_rows) != 1:
        raise DataContractError("metrics query must return exactly one row")
    return tuple(int(value) for value in result.result_rows[0])


def read_exact_schema(
    client: ClickHouseClient,
    relation: RelationName,
) -> tuple[tuple[str, str], ...]:
    result = client.query(
        """
        select name, type
        from system.columns
        where database = {database:String}
          and table = {table:String}
        order by position
        """,
        {"database": relation.database, "table": relation.table},
    )
    if tuple(result.column_names) != ("name", "type"):
        raise DataContractError("schema query returned unexpected columns")
    return tuple((str(row[0]), str(row[1])) for row in result.result_rows)


METRIC_COLUMNS = (
    "row_count",
    "distinct_key_count",
    "empty_key_count",
    "null_count",
    "invalid_source_count",
    "invalid_type_count",
    "invalid_target_count",
    "invalid_time_count",
    "invalid_formula_count",
    "missing_lineage_count",
)


def validate_training_data_contract(
    client: ClickHouseClient,
    config: TrainingDataContractConfig,
    *,
    now_utc: datetime | None = None,
) -> ValidationReport:
    relation = RelationName.parse(config.relation)
    lineage = RelationName.parse(config.lineage_relation)
    actual_schema = read_exact_schema(client, relation)
    expected_schema = tuple(
        (column.name, column.clickhouse_type) for column in config.expected_columns
    )
    if not actual_schema:
        raise DataContractError("training relation does not exist")
    if actual_schema != expected_schema:
        raise DataContractError(
            f"exact schema mismatch: expected={expected_schema!r}, "
            f"actual={actual_schema!r}"
        )

    metrics_result = client.query(
        f"""
        lineage as (
            select source, event_id, toUInt8(1) as lineage_matched
            from {lineage.quoted()}
        )
        select
            count() as row_count,
            uniqExact(tuple(t.source, t.event_id))
                as distinct_key_count,
            countIf(trim(t.source) = '' or trim(t.event_id) = '')
                as empty_key_count,
            countIf(
                t.source is null
                or t.event_id is null
                or t.event_time is null
                or t.event_date is null
                or t.step is null
                or t.transaction_type is null
                or t.amount is null
                or t.origin_balance_before is null
                or t.origin_balance_after is null
                or t.destination_balance_before is null
                or t.destination_balance_after is null
                or t.is_fraud is null
            ) as null_count,
            countIf(t.source != {{expected_source:String}})
                as invalid_source_count,
            countIf(
                not has({{types:Array(String)}}, t.transaction_type)
            ) as invalid_type_count,
            countIf(t.is_fraud not in (0, 1))
                as invalid_target_count,
            countIf(
                t.event_time
                != toDateTime64(
                    {{replay_epoch:String}},
                    3,
                    'UTC'
                ) + toIntervalHour(t.step)
                or t.event_date != toDate(t.event_time)
            ) as invalid_time_count,
            countIf(
                t.origin_balance_delta
                    != t.origin_balance_before - t.origin_balance_after
                or t.destination_balance_delta
                    != t.destination_balance_after
                       - t.destination_balance_before
                or t.origin_amount_residual
                    != abs(t.origin_balance_delta - t.amount)
                or t.destination_amount_residual
                    != abs(t.destination_balance_delta - t.amount)
            ) as invalid_formula_count,
            countIf(ifNull(l.lineage_matched, 0) = 0)
                as missing_lineage_count
        from {relation.quoted()} as t
        left join lineage as l
            on t.source = l.source
           and t.event_id = l.event_id
        """,
        {
            "expected_source": config.expected_source,
            "types": list(config.transaction_type_domain),
            "replay_epoch": config.replay_epoch_utc.isoformat().replace("+00:00", "Z"),
        },
    )
    values = parse_one_metrics_row(metrics_result, METRIC_COLUMNS)
    metrics = ContractMetrics(*values)

    violations = {
        "duplicate_key_count": (metrics.row_count - metrics.distinct_key_count),
        "empty_key_count": metrics.empty_key_count,
        "null_count": metrics.null_count,
        "invalid_source_count": metrics.invalid_source_count,
        "invalid_type_count": metrics.invalid_type_count,
        "invalid_target_count": metrics.invalid_target_count,
        "invalid_time_count": metrics.invalid_time_count,
        "invalid_formula_count": metrics.invalid_formula_count,
        "missing_lineage_count": metrics.missing_lineage_count,
    }
    failed = {name: value for name, value in violations.items() if value != 0}
    if metrics.row_count == 0:
        failed["row_count"] = 0
    if failed:
        raise DataContractError(f"contract violations: {failed}")

    validated_at = (now_utc or datetime.now(UTC)).astimezone(UTC)
    return ValidationReport(
        dataset_name=config.dataset_name,
        relation=config.relation,
        validated_at_utc=validated_at.isoformat().replace("+00:00", "Z"),
        schema=actual_schema,
        metrics=metrics,
    )
```

Không thêm tolerance float vào invariant vì các cột là `Decimal(18, 2)`; phép
tính contract phải exact ở cùng scale.

```python
from __future__ import annotations

import os
from dataclasses import dataclass, field
from typing import Any

import clickhouse_connect


@dataclass(frozen=True)
class ClickHouseSettings:
    host: str
    port: int
    username: str
    password: str = field(repr=False)
    database: str = "fraudguard"
    secure: bool = False

    @classmethod
    def from_env(cls) -> ClickHouseSettings:
        password = os.getenv("ML_CLICKHOUSE_PASSWORD")
        if not password:
            raise ValueError("ML_CLICKHOUSE_PASSWORD must be set")

        port_text = os.getenv("ML_CLICKHOUSE_PORT", "8123")

            port = int(port_text)

        if secure_text not in {"true", "false"}:
            raise ValueError("ML_CLICKHOUSE_SECURE must be true or false")

        username = os.getenv(
            "ML_CLICKHOUSE_USER",
            "fraudguard_transformer",

        if username != "fraudguard_transformer":
            raise ValueError("ML_CLICKHOUSE_USER must be fraudguard_transformer")
        database = os.getenv("ML_CLICKHOUSE_DATABASE", "fraudguard")
        if database != "fraudguard":
            raise ValueError("ML_CLICKHOUSE_DATABASE must be fraudguard")

        return cls(
            host=os.getenv("ML_CLICKHOUSE_HOST", "localhost"),
            port=port,
            username=username,
            password=password,
            database=database,
            secure=secure_text == "true",
        )

        port=settings.port,
```

```python
from __future__ import annotations

import argparse
import json
from collections.abc import Sequence
from dataclasses import asdict
from pathlib import Path

from clickhouse_connect.driver.exceptions import ClickHouseError
from pydantic import ValidationError

from fraudguard_ml.clickhouse import (
    ClickHouseSettings,
    create_clickhouse_client,
)
from fraudguard_ml.config import SmokeConfig, load_yaml_config
from fraudguard_ml.training_data_contract import (
    DataContractError,
    TrainingDataContractConfig,
    validate_training_data_contract,
)


def build_parser() -> argparse.ArgumentParser:
    parser = argparse.ArgumentParser(prog="fraudguard")
    commands = parser.add_subparsers(dest="command", required=True)

    smoke = commands.add_parser("smoke")
    smoke.add_argument("--config", type=Path, required=True)
    smoke.add_argument("--json", action="store_true", dest="json_output")

    validate = commands.add_parser("validate-training-data")
    validate.add_argument("--config", type=Path, required=True)
    return parser


def run_validate_training_data(config_path: Path) -> int:
    config = load_yaml_config(
        config_path,
        TrainingDataContractConfig,
    )
    client = create_clickhouse_client(ClickHouseSettings.from_env())
    try:
        report = validate_training_data_contract(client, config)
    finally:
        client.close()
    print(json.dumps(asdict(report), indent=2, sort_keys=True))
    return 0


def main(argv: Sequence[str] | None = None) -> None:
    parser = build_parser()
    args = parser.parse_args(argv)
    try:
        if args.command == "validate-training-data":
            exit_code = run_validate_training_data(args.config)
        elif args.command == "smoke":
            load_yaml_config(args.config, SmokeConfig)
            exit_code = 0
        else:
            parser.error(f"unknown command: {args.command}")
    except (OSError, ValueError, ValidationError, DataContractError) as exc:
        parser.exit(2, f"validation error: {exc}\n")
    except ClickHouseError:
        parser.exit(2, "ClickHouse validation request failed\n")
    raise SystemExit(exit_code)
```

## D2. Provenance helper

**File đích:** `ml/src/fraudguard_ml/artifacts.py`
```python
from __future__ import annotations

import hashlib
import json
import os
import subprocess
import tempfile
from collections.abc import Mapping, Sequence
from pathlib import Path
from typing import Any


class ArtifactError(RuntimeError):
    """Artifact cannot be proven reproducible or written atomically."""


def sha256_file(path: Path) -> str:
    digest = hashlib.sha256()
    try:
        with path.open("rb") as stream:
            for chunk in iter(lambda: stream.read(1024 * 1024), b""):
                digest.update(chunk)
    except OSError as exc:
        raise ArtifactError(f"cannot hash required file: {path}") from exc
    return digest.hexdigest()


def git_output(root: Path, arguments: Sequence[str]) -> str:
    try:
        completed = subprocess.run(
            ["git", *arguments],
            cwd=root,
            check=True,
            capture_output=True,
            text=True,
        )
    except (OSError, subprocess.CalledProcessError) as exc:
        raise ArtifactError("cannot inspect Git provenance") from exc
    return completed.stdout.strip()


def collect_git_provenance(
    repository_root: Path,
    relevant_paths: Sequence[Path],
) -> dict[str, Any]:
    relative_paths = [str(path.relative_to(repository_root)) for path in relevant_paths]
    status = git_output(
        repository_root,
        ["status", "--porcelain", "--", *relative_paths],
    )
    if status:
        raise ArtifactError("relevant source/config paths must be committed and clean")
    return {
        "git_sha": git_output(repository_root, ["rev-parse", "HEAD"]),
        "relevant_paths_clean": True,
        "relevant_paths": sorted(relative_paths),
    }


def build_artifact(
    *,
    report: Mapping[str, Any],
    repository_root: Path,
    contract_path: Path,
    lock_path: Path,
    dbt_manifest_path: Path,
    relevant_paths: Sequence[Path],
) -> dict[str, Any]:
    git = collect_git_provenance(repository_root, relevant_paths)
    return {
        "artifact_schema_version": 1,
        "status": "validated",
        "validation": dict(report),
        "provenance": {
            **git,
            "sha256": {
                "contract": sha256_file(contract_path),
                "lockfile": sha256_file(lock_path),
                "dbt_manifest": sha256_file(dbt_manifest_path),
            },
            "dbt_selection": "+tag:training",
        },
    }


def write_json_atomic(
    destination: Path,
    payload: Mapping[str, Any],
) -> None:
    destination.parent.mkdir(parents=True, exist_ok=True)
    temporary_path: Path | None = None
    try:
        with tempfile.NamedTemporaryFile(
            mode="w",
            encoding="utf-8",
            dir=destination.parent,
            prefix=f".{destination.name}.",
            suffix=".tmp",
            delete=False,
        ) as stream:
            temporary_path = Path(stream.name)
            json.dump(
                payload,
                stream,
                indent=2,
                sort_keys=True,
                ensure_ascii=False,
            )
            stream.write("\n")
            stream.flush()
            os.fsync(stream.fileno())
        os.replace(temporary_path, destination)
        temporary_path = None
    except OSError as exc:
        raise ArtifactError(f"cannot atomically write artifact: {destination}") from exc
    finally:
        if temporary_path is not None:
            temporary_path.unlink(missing_ok=True)
```

`relevant_paths` tối thiểu gồm contract, Python validator/client/CLI/artifact
module, `pyproject.toml`, `uv.lock`, dbt project, training/core SQL và các dbt
test tạo trust gate. Nếu một file liên quan untracked hoặc dirty thì lệnh
handoff fail; không được ghi artifact với Git SHA không đại diện cho code thực
thi.

```python
import json

import pytest

from fraudguard_ml.artifacts import ArtifactError, write_json_atomic


def test_atomic_writer_replaces_complete_json(tmp_path) -> None:
    output = tmp_path / "contract.json"
    output.write_text('{"old": true}\n', encoding="utf-8")

    write_json_atomic(output, {"status": "validated"})

    assert json.loads(output.read_text(encoding="utf-8")) == {"status": "validated"}
    assert list(tmp_path.glob(".*.tmp")) == []


def test_atomic_writer_keeps_no_temporary_file_on_failure(
    monkeypatch,
    tmp_path,

    output = tmp_path / "contract.json"

    def fail_replace(source, destination) -> None:
        raise OSError("simulated")

    monkeypatch.setattr("fraudguard_ml.artifacts.os.replace", fail_replace)

    assert list(tmp_path.glob(".*.tmp")) == []
```

# 4. Definition of Done của M1

M1 chỉ hoàn thành khi tất cả điều sau đều đúng:

## Data foundation

- ClickHouse chỉ có database dự án `fraudguard`;
- folder/tag dbt biểu diễn logical layer, không tạo database theo layer;
- transformer role hiện có materialize model trong `fraudguard`;
- dbt parse không có stale documentation patch;
- `has_final_label` và reconciliation join dùng match marker;
- không dùng empty string hay số 0 làm unmatched sentinel;
- business key non-null, non-empty, unique;
- quality invariant là `input_rows = valid_rows + quarantine_rows`;
- targeted `+tag:training` build pass.

## Training contract

- relation là `fraudguard.ml_training_transactions`;
- schema có đúng 16 cột đúng order/type;
- dataset không rỗng;
- source/type/target/time domain hợp lệ;
- delta và residual được recompute, không chỉ tin cột materialized;
- mọi training key truy được về canonical core key;
- feature policy phân biệt identity/time/target/audit candidate.

## Safety

- không tạo role/user/database mới;
- CLI dùng transformer hiện có nhưng session `readonly=1`;
- password bị loại khỏi repr và error;
- identifier validate/quote và value parameterize;
- client được đóng ở mọi path;
- không có secret trong repository hoặc artifact.

## Reproducibility

- config, dependency và lockfile đồng bộ;
- report chứa schema/metrics/timestamp;
- artifact chứa Git SHA và hash contract/lock/manifest;
- relevant source/config paths committed và clean;
- artifact write atomic;
- lineages và dbt selection được ghi rõ.
